# Interruptores ↔ luces — hasta 10 parejas

Blueprint heredado que agrupa hasta diez parejas de interruptor y luz dentro de
una sola automatización.

[![Importar Blueprint](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https://raw.githubusercontent.com/ejscuriel/ha-blueprints/main/blueprints/automation/switch_light/BP_Multi_Switch_Light.yaml)

Se conserva para instalaciones existentes y reversión. Para instalaciones
nuevas se recomienda [Interruptor ↔ Luz — una pareja](../switch_light_single/README.md),
que mantiene trazas y ejecuciones independientes.
